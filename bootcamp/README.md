# Cloud Security Python Bootcamp

Interactive Python training built around this repo's attack simulation scripts.

## Live App
https://gregqlewis.github.io/cloud-attack-detection-lab/bootcamp/

## What It Teaches
- Python fundamentals through real CloudTrail event parsing
- Loops, conditionals, functions via actual attack simulation patterns
- Classes and OOP by building a CloudTrailAnalyzer
- All concepts mapped to MITRE ATT&CK techniques

## Stack
React + Vite, deployed to GitHub Pages
